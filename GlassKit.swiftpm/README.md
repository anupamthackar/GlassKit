# GlassKit Playgrounds App

This is a self-contained demonstration of the **GlassKit (NovaUI)** design system.

## 📱 Features
- **Liquid Glass Primitives**: High-performance glass-morphic surfaces.
- **Token Catalog**: Exploration of the typography and spacing systems.
- **Interactive Components**: Real-time feedback for buttons, inputs, and navigation.
- **AI Streaming**: Simulation of AI-driven text interfaces.

## 🛠 Tech Stack
- **Swift 6**: Full concurrency compliance.
- **SwiftUI**: Modern declarative UI.
- **Metal / GPU**: Optimized rendering for glass materials.

## 🚀 How to Run
1. Open `GlassKit.swiftpm` in **Swift Playgrounds** on iPad or Mac.
2. Or open the folder in **Xcode**.
3. Tap "Run" to explore the catalog.
